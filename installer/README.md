# Установщик RaskolHUD для Windows

Установщик размещает в стандартной папке `%APPDATA%\.minecraft\mods`:

- `raskolhud-client-0.5.0.jar` — клиентский HUD;
- `fabric-api-0.161.0+26.2.jar` — зависимость Fabric API.

Поддерживаемая конфигурация: Minecraft 26.2, Java 25, Fabric Loader 0.19.5.

Установщик не устанавливает Minecraft, Java или Fabric Loader и не меняет сторонние профили/каталоги лаунчеров. Если игра запускается из отдельного каталога, файлы нужно перенести в папку `mods` этого профиля вручную.

Перед копированием удаляются только старые файлы с именами `raskolhud-client-*.jar` и `fabric-api-*.jar` в стандартной папке. Остальные моды не затрагиваются.

Сборка выполняется в Windows GitHub Actions: клиентский JAR собирается из закреплённого коммита репозитория RaskolHUD-mod, Fabric API загружается с официального Maven Fabric, затем оба файла упаковываются Inno Setup. SHA-256 публикуется рядом с EXE.
