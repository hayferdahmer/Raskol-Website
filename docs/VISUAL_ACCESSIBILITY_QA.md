# Visual & Accessibility QA · 16 ноября 2026

## Область проверки

Браузерный прогон выполнен в Chromium через Playwright. Проверены все 21 маршрут сайта на четырёх ширинах:

- Desktop — 1440 px
- Tablet — 768 px
- Mobile — 390 px
- Small mobile — 320 px

Всего: **84 комбинации маршрута и viewport**, 84 скриншота.

### Проверенные маршруты

- Главная.
- Мир, фракции, экосистема, карта и медиа.
- Каталог классов, шесть классов, каталог специализаций и дерево талантов «Оружие».
- Магазин, аккаунт и поддержка.
- Оферта, политика конфиденциальности и правила.

## Результаты автоматизированного прогона

| Проверка | Результат |
|---|---:|
| Горизонтальное переполнение | 0 |
| Нарушения axe-core | 0 |
| Critical / serious / moderate axe | 0 |
| Ошибки JavaScript во время загрузки и сценариев | 0 |
| Замечания клавиатурных проверок | 0 |
| Замечания reduced-motion | 0 |
| Скриншоты | 84 |

axe-core запускался для всех четырёх viewport на каждом маршруте. Нулевой результат означает, что автоматический сканер не обнаружил нарушений в проверенных состояниях; это не является полной сертификацией доступности.

## Проверенные интерактивные сценарии

- Диалог товара: открытие, первоначальный фокус на кнопке закрытия, Escape, возврат фокуса на исходный товар.
- Диалог кейса: открытие и закрытие с клавиатуры.
- Рулетка: завершение сценария при `prefers-reduced-motion: reduce` и доступное объявление результата.
- Вкладки аккаунта: навигация стрелками и доступное имя панели.
- Музыкальный плеер: компактное состояние при первом посещении на desktop и mobile, раскрытие по кнопке.
- Поле поиска магазина: заметное состояние клавиатурного фокуса.
- Skip-link и основной landmark проверяются на всех страницах.

## Исправления по результатам визуального просмотра

- Устранено переполнение hero магазина на планшетной ширине за счёт треков `minmax(0, ...)`.
- Навигация магазина до 980 px перенесена в отдельную горизонтально прокручиваемую строку; она не выпадает из шапки.
- На очень узких экранах уменьшены размеры шапки и художественного блока магазина, чтобы сохранить место для содержания и действий.
- Музыкальный плеер по умолчанию свёрнут, остаётся компактным прозрачным значком; на мобильных экранах он расположен справа. Выбор пользователя раскрыть плеер сохраняется между переходами.
- Для поиска, поля кода, лимитов и email-поля магазина добавлены явные focus-ring стили, поскольку базовые `outline: none` не наследовали общий фокусный стиль.
- Главная проверена как визуальный эталон: композиция и основной hero не перерабатывались.

## Ограничения проверки

- Использовался Chromium; Firefox и WebKit/Safari не запускались.
- Не выполнялись ручные сессии с NVDA, VoiceOver и TalkBack, а также тесты на физических устройствах.
- Автоматические проверки не заменяют проверку всех потоков экранным диктором, пользовательское тестирование и проверку в реальных браузерах.
- Магазин, кейсы, баланс и аккаунт остаются демонстрационными; QA не подключает платежи или серверную авторизацию.
