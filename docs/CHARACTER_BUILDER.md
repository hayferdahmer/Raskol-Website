# Конструктор персонажа РАСКОЛА

**Статус:** проектирование, без расчёта игровых характеристик  
**Задача:** дать игроку возможность изучать классы, специализации, таланты и экипировку до входа в игру.

## Основной пользовательский сценарий

1. Выбрать один из подтверждённых классов.
2. Выбрать специализацию, доступную этому классу.
3. Изучить способности, таланты и ресурсную модель.
4. Собрать план талантов/экипировки, когда точные данные будут подтверждены.
5. Сохранить сборку локально или поделиться ссылкой без регистрации.
6. Сравнить сборки после появления утверждённых правил расчёта.

## Первый релиз

Первая версия — справочный planner, не симулятор боя:
- выбор класса и специализации;
- карточка роли и подтверждённого описания;
- список связанных способностей;
- заметки игрока;
- локальное сохранение сборки и экспорт/импорт JSON;
- ссылка на каноническую страницу специализации.

## Следующий релиз

После подтверждения данных в игровых плагинах:
- дерево талантов с prerequisites;
- ограничения очков и уровней;
- подбор экипировки по слотам;
- сравнение характеристик;
- проверка допустимости сборки по версии игры.

## Достоверность данных

Каждое правило должно иметь версию и источник. Для расчётных механик нужны:
- точная формула;
- порядок округления;
- ограничения и исключения;
- версия плагина/конфигурации;
- тестовые примеры, сверенные с сервером.

До этого нельзя выводить «итоговый DPS», проценты эффективности, оптимальную сборку или обещать совпадение с сервером.

## Техническая модель

- Статические данные классов и специализаций загружаются из общего каталога.
- Сборка имеет `schemaVersion`, `gameVersion`, `classId`, `specializationId`, `notes` и массив выбранных опций.
- Сохранение без аккаунта — в браузере пользователя; экспорт JSON позволяет переносить сборку.
- При изменении схемы импорт должен проверять версию и выдавать понятную ошибку, а не молча терять выбор.
- Не помещать в сборку UUID, токены или приватные данные игрока.

## Проверки

- Нельзя выбрать специализацию чужого класса.
- Нельзя импортировать неизвестную версию схемы без предупреждения.
- Все состояния доступны с клавиатуры и screen reader.
- Сборка не теряется при обычной навигации.
- Расчёты включаются только при наличии подтверждённой версии правил и тестов.
