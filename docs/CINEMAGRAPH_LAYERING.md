# Подготовка Cinemagraph для цитадели RASKOL

## Неподвижная основа

Исходная иллюстрация цитадели — неизменяемый base layer. Не применять к ней генеративную перерисовку, деформацию, optical flow или video-to-video. Архитектура, башни, стены, перспектива и кадр должны оставаться пиксельно неизменными.

## Слои, которые подготовим отдельно

1. **Clouds** — прозрачный слой облаков, отделённый от силуэта цитадели; очень медленное горизонтальное движение.
2. **Mist back** — дальняя дымка за стенами и башнями, мягкое движение в противоположном направлении.
3. **Mist front** — передний туман, отдельная маска, более заметный параллакс.
4. **Embers** — немного редких частиц/углей, без перекрытия важных деталей герба и архитектуры.
5. **Light** — локальные маски света в окнах/фонарях; только лёгкое мерцание, без глобального изменения яркости.

## Контракт разметки

Контейнер сцены получает атрибут data-rsk-cinemagraph. Каждый прозрачный слой — отдельный элемент с data-rsk-cinema-layer и одним из значений: clouds, mist-back, mist-front, embers, light. Исходное изображение должно быть отдельным нижним слоем, не включённым в анимационные селекторы.

Для слоёв использовать CSS custom properties: --rsk-cinema-depth (z-index слоя) и --rsk-cinema-opacity (максимальная прозрачность).

Активация сцены привязана к IntersectionObserver. При выходе из viewport класс активности снимается. При prefers-reduced-motion движение отключено.

## Требования к завтрашним исходникам

- Все слои должны совпадать по размерам холста и точке привязки с оригинальной иллюстрацией.
- Формат: прозрачный WebP/PNG; маски света — grayscale PNG/WebP.
- Не дорисовывать и не удалять архитектурные элементы.
- Облака и туман должны быть бесшовными или иметь достаточный запас за границами кадра.
- Для каждого слоя сохранить исходный файл и маску отдельно.

## Текущее состояние

Добавлены только CSS-примитивы и активация сцен по видимости. Пока контейнер и реальные слои не размечены и не подготовлены, главная визуально не меняется. Это намеренно: пустые или синтетические маски не должны имитировать готовый cinemagraph.
