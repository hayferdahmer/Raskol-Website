# Портал игрового мира РАСКОЛ

## Состав первого этапа

- `/world/` — обзор мира и его подтверждённой политической структуры.
- `/factions/` — два королевства и независимые вольные города.
- `/systems/` — обзор направлений собственной игровой разработки.
- `/map/` — переход к живой карте BlueMap + MapTowny.

## Канонические сведения

- Два королевства: Рассвет и Вальрадис.
- Основной город Рассвета в текущих землях: Лайтрис.
- Основной город Вальрадиса в текущих землях: Драгос.
- Вольные города независимы и не входят в состав королевств.
- На старте игрок выбирает класс, затем примыкает к одному из двух королевств.
- Сейчас попасть в вольный город можно, покинув своё королевство.
- Возможность изначально начинать вне королевства относится к будущему развитию.

## Карта

Единственный источник фактической географии в этом разделе — BlueMap + MapTowny:

http://143.20.155.14:25731/#world:-456:0:356:1500:0:0:0:1:flat

На сайте не создаются вымышленные координаты, адреса и точки. Карта открывается отдельно, поскольку текущий адрес использует HTTP, а GitHub Pages — HTTPS; браузер может блокировать HTTP iframe как смешанный контент.

## Редакционные ограничения

- Не добавлять историю раскола, правителей, гербы, бонусы королевств, дипломатические отношения и другие неподтверждённые элементы лора.
- Не представлять вольные города как третье королевство.
- Не объявлять будущий свободный старт доступной механикой.
- Не считать наличие плагина в GitHub доказательством доступности его функций игрокам.
- Состав кастомных плагинов может меняться и объединяться; публичный раздел описывает игровые направления, а не технический каталог репозиториев.
- Статус каждой функции уточняется отдельно после проверки на целевом сервере.
