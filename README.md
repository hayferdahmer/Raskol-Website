# РАСКОЛ — Две короны · базовая версия сайта 2.1

Это сохранённая и технически подчищенная версия `RASKOL-Visual-Identity-2.1`, выбранная как текущая базовая версия сайта. Визуальный стиль и композиция исходной страницы сохранены; это не редизайн.

## Файлы

- `index.html` — главная страница (CSS, JS и большие фоновые изображения встроены в HTML).
- `shop/index.html` — демонстрационная витрина и Чертог кейсов; `account/index.html` — демонстрационный личный кабинет.
- `classes/` — страницы шести классов, каталог специализаций и эталонная страница специализации «Оружие».
- `world/`, `factions/`, `systems/`, `map/`, `media/` — портал мира, королевства и вольные города, обзор игровых систем и переход к живой карте BlueMap.
- `rules.html`, `offer.html`, `privacy.html` — правила и временные страницы юридических документов. Оферта и политика конфиденциальности **не являются финальными юридическими документами**.

## Документация сайта

- [`docs/SITE_MAP.md`](docs/SITE_MAP.md) — полная карта разделов, маршрутов и этапов развития портала.
- [`docs/HOMEPAGE_CONTENT.md`](docs/HOMEPAGE_CONTENT.md) — структура главной страницы и готовые тексты для блоков.
- [`docs/WORLD_PORTAL_CONTENT.md`](docs/WORLD_PORTAL_CONTENT.md) — канонические сведения и редакционные ограничения портала мира.

- [`docs/contracts/public-api-v1.json`](docs/contracts/public-api-v1.json) — пример публичного JSON-контракта v1.
- [`docs/ENCYCLOPEDIA_ARCHITECTURE.md`](docs/ENCYCLOPEDIA_ARCHITECTURE.md) — модель данных и структура будущей игровой энциклопедии.
- [`docs/CHARACTER_BUILDER.md`](docs/CHARACTER_BUILDER.md) — этапы и правила конструктора персонажа.

## Платформа сервера

Целевая серверная платформа RASKOL: **Minecraft 26.2 · Paper 26.2 · Java 25**. Версию клиента и требования к подключению следует публиковать только после отдельной проверки фактической конфигурации игрового сервера.

## Как посмотреть локально

Откройте `index.html` в актуальном Chrome или Edge. Для публикации используйте статический хостинг.

## Публикация через GitHub Pages

Репозиторий сайта: `https://github.com/hayferdahmer/Raskol-Website`.

Для публикации текущей версии откройте **Settings → Pages** и проверьте настройки **Deploy from a branch → `main` → `/(root)`**. Все HTML-страницы, общие CSS/JS и документация должны оставаться в структуре репозитория: не загружайте только главную страницу отдельно. Адрес публикации: `https://hayferdahmer.github.io/Raskol-Website/`.

Главная страница использует шесть SVG-эмблем из публичного репозитория `hayferdahmer/RaskolClasses`, путь `docs/assets/emblems/`. Все шесть файлов проверены и существуют в `main`. При переносе или переименовании того репозитория ссылки на эмблемы нужно будет обновить.

Google Fonts загружаются из сети; при отсутствии интернета страница использует системные шрифты. Основные фоновые изображения уже встроены в `index.html`.

## Что пока намеренно не подключено

- Публичные адреса подключения: Anycast `raskolpro.play.ski` и SRV `raskol.play.ski`. Прямой IP и внутреннее имя хоста не публикуются.
- Web API Bridge пока описан архитектурно и **не развернут**. Статус сервера не запрашивается автоматически; не показывать вымышленные значения онлайна и версии.
- BlueMap, Plan и DiscordSRV рассматриваются как отдельные интеграции. Их наличие/работоспособность на production-сервере нужно подтвердить до публикации активных ссылок.
- Магазин империалов не принимает оплату; карточки показывают, что раздел готовится.
- Медиаархив создан как раздел для будущих скриншотов, видео, официальных трейлеров обновлений и проверенных прямых эфиров. Интеграция стримов пока не подключена.
- Энциклопедия и конструктор персонажа пока находятся на этапе проектирования данных; расчёты и неподтверждённые игровые характеристики не публикуются.
- Страницы правил, оферты и конфиденциальности нужно заменить утверждёнными текстами до запуска сервера и любых платных функций.
- Данные продавца и контактные сведения нужно добавить до открытия платных функций.

## Проверки

- Синтаксис JavaScript проверен через `node --check`.
- HTML разобран парсером; проверены повторяющиеся ID, якорные ссылки и необходимые JS-селекторы.
- Полноценный визуальный прогон в браузере в этой среде не удалось завершить: headless Chromium зависает при открытии `file://`. Поэтому визуальная проверка на реальном устройстве остаётся обязательной.
