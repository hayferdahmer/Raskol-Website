# Каталог «Опционально» — регламент наполнения

Публичная страница: `/optional/`.

## Данные карточки
Название, категория, описание, версия Minecraft, загрузчик и зависимости, системные требования, размер и формат файла, SHA-256, официальный источник, автор и лицензия, инструкция установки и удаления, известные конфликты, результат тестирования и оригинальные скриншоты при необходимости.

## Процесс публикации
1. Получить файл и исходную ссылку.
2. Изучить состав архива, пути, вложенные архивы и исполняемые компоненты.
3. Не запускать неизвестные бинарные файлы и установщики.
4. Проверить происхождение, автора, лицензию и право на повторное размещение.
5. Сверить версии и зависимости; провести тест совместимости.
6. Подготовить инструкцию и SHA-256.
7. Только после проверки разместить файл и добавить ссылку на страницу.

## Правила
- Не публиковать непроверенные архивы или материалы с неясной лицензией.
- Не обещать совместимость до практической проверки.
- Не включать чит-клиенты, обходы ограничений, серверные инжекторы и сомнительные загрузчики.
- Не хранить секреты, токены, приватные адреса и персональные данные.
- По возможности ссылаться на официальный источник автора.
- Для размещённых файлов сохранять версию и SHA-256.

## Текущий статус
Страница и структура каталога подготовлены. Реальных загрузок пока нет; позиции добавляются после получения и проверки материалов.


## Опубликованная позиция: RaskolHUD 0.5.1

- Категория: клиентский мод / интерфейс.
- Файл: `RaskolHUD-Installer-0.5.1.exe` (Windows x64).
- Состав: `raskolhud-client-0.5.1.jar` и `fabric-api-0.161.0+26.2.jar`.
- Игра: Minecraft 26.2.
- Загрузчик: Fabric Loader 0.19.5 или новее, совместимый с Minecraft 26.2.
- Java: 25.
- Установка: стандартная папка `%APPDATA%\.minecraft\mods`. Для отдельного каталога стороннего лаунчера требуется ручное копирование файлов в `mods` конкретного профиля.
- Установщик удаляет только старые файлы RaskolHUD и Fabric API по соответствующим шаблонам имён, остальные моды не затрагивает.
- Исходный код мода: https://github.com/hayferdahmer/RaskolHUD-mod
- Сборка клиента закреплена на коммите `632693391188c0c6222b21123721fd48b69c6cc7`.
- Fabric API скачивается с официального Maven Fabric: https://maven.fabricmc.net/
- Выпуск установщика и файл SHA-256: https://github.com/hayferdahmer/Raskol-Website/releases/tag/raskolhud-installer-v0.5.1

Ограничения: установщик не устанавливает Minecraft, Java или Fabric Loader; не настраивает сторонние лаунчеры; не включает серверный Paper-мост. Перед запуском игры закрой Minecraft Launcher и саму игру.
